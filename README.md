# sdeparis Premium Jewelry Website

Luxury white jewelry website ready for GitHub Pages.

Includes:
- White premium design
- Black typography with subtle champagne accents
- 8 jewelry products with sample prices
- Women / Men / Gifts filters
- Collections and gifting sections
- Brand story and editorial styling
- Testimonials, FAQ, newsletter and contact
- Custom logo and favicon
- Responsive layout and animations

Important: prices, testimonials and forms are demo content. Replace them with real business information before commercial use.

Upload all files to the root of `sdeparis.github.io` and keep `index.html` in the repository root.
